# MSPM0G3507 双轮小车控制工程

基于 TI MSPM0G3507、DriverLib 和裸机主循环，实现双轮差速小车的速度 PI 闭环、四路红外巡线、按键控制及串口调参。工程从 SDK 的 `empty` 示例扩展而来，CCS 工程名仍为 `empty_LP_MSPM0G3507_nortos_ticlang`。

电机 PWM 由外部串口驱动板输出，编码器速度也由驱动板上报；MSPM0 负责计算左右轮目标速度和 PI 输出，不直接采集编码器脉冲。

> 编译和主机测试不代表实车效果已验证；接线、传感器电平、电机方向及参数效果需在实车上确认。

## 功能与默认参数

| 项目 | 当前实现 |
| --- | --- |
| 运行方式 | 裸机主循环，无 RTOS；SysTick 提供 1 ms 时基 |
| 速度档位 | 150 / 300 / 600 mm/s，上电默认 150 mm/s |
| 速度控制 | 左右轮独立 PI，新有效速度反馈帧到达时更新 |
| PI 初值 | `Kp = 1.5`，`Ki = 8.0`，无微分项 |
| 输出限幅 | PWM：±3600；积分项：±1800 |
| 巡线 | 默认开启，20 ms 更新一次；白色高电平、黑色低电平 |
| 巡线系数 | `Kp = 0.1`，允许范围 0～1；转向直接按比例计算，不另作转向限幅或平滑 |
| 盲区处理 | 有可靠历史时，从最近可靠检测计时，失检不足 200 ms 统一为间隙保持，使用最后可靠偏差，为 0 则直行；达到 200 ms 仍未确认找回则停车等待，基础速度保持当前档位 |
| 停车条件 | 按键停止、反馈或控制更新超时、全黑及非相邻黑线；全白失检停车等待，可连续 3 次正常检测后恢复，详见下文 |
| 速度遥测 | 保留 60 ms 四路速度遥测函数，当前主循环调用已注释 |

## 硬件连接

需要兼容下述串口协议的电机驱动板、带编码器的左右电机、四路数字红外巡线模块和三个低电平有效按键。驱动板具体型号未在源码中明确，接入前需核对协议、供电及逻辑电平，并使各模块共地。

### 引脚分配

| 功能 | 外设 / 信号 | MCU 引脚 | 连接说明 |
| --- | --- | --- | --- |
| 电机驱动板串口发送 | UART1 TX | PB6 | 接驱动板 RX |
| 电机驱动板串口接收 | UART1 RX | PB7 | 接驱动板 TX |
| PC 串口发送 | UART0 TX | PA10 | XDS110 USB 回传通道 |
| PC 串口接收 | UART0 RX | PA11 | XDS110 USB 回传通道 |
| PC 备用串口发送 | UART2 TX | PA21 | 接 3.3 V USB 转串口模块 RX |
| PC 备用串口接收 | UART2 RX | PA22 | 接 3.3 V USB 转串口模块 TX |
| K1 | GPIO 输入，上拉 | PA2 | 按下接地，启动 / 停止 |
| K2 | GPIO 输入，上拉 | PB19 | 按下接地，运行时换挡 |
| K3 | GPIO 输入，上拉 | PB20 | 按下接地，切换巡线 |
| 巡线 S0 | GPIO 输入 | PA24 | 权重 +3 |
| 巡线 S1 | GPIO 输入 | PA25 | 权重 +1 |
| 巡线 S2 | GPIO 输入 | PA27 | 权重 −1 |
| 巡线 S3 | GPIO 输入 | PA26 | 权重 −3 |
| 状态输出 | GPIO 输出 | PB2 | 代码实例名为 `LED1`，巡线开启时每轮主循环翻转 |
| SWD 时钟 / 数据 | SWCLK / SWDIO | PA20 / PA19 | 连接 XDS110 |

三路 UART 均为 **115200 baud、8 数据位、无校验、1 停止位、无硬件流控（8N1）**。

- K1/K2/K3 是本工程的按键定义，不对应 LaunchPad 自带的 S1/S2；三个按键均有 20 ms 按下及松开消抖。
- PB2 是本工程配置的状态输出，并非 LaunchPad 板载 LED1 所在的 PA0。翻转没有固定周期，不能据此判断控制周期。
- 使用 LaunchPad 的 XDS110 回传串口时，J21/J22 应处于 `[1:2]`，在电脑端选择 `XDS110 Class Application/User UART`。
- UART2 使用外接 3.3 V USB 转串口模块，TX/RX 交叉连接并共地。两路 PC 串口同时可用，换线后选择对应的电脑端口即可，无需修改程序或重新烧录。
- 使用 LP-MSPM0G3507 时，PA22 与板载光传感器电路相连，作为 UART2 RX 使用前应移除 J16。
- PA26、PA27 与 LaunchPad 板载光传感器电路相连，外接巡线模块时应移除对应的 J18、J17 跳线，避免电路干扰。
- S0～S3 的物理排列和轮子正方向需通过实车验证，使偏差与差速修正方向一致。

### 电机通道

驱动板协议按四个通道传输，软件数组按 **0～3** 索引：

| 车轮 | 软件索引 | 四通道报文位置 |
| --- | --- | --- |
| 左轮 | `LEFT_MOTOR_ID = 1` | 第 2 项 |
| 右轮 | `RIGHT_MOTOR_ID = 0` | 第 1 项 |

正常闭环仅更新上述两路，其余两路输出为 0。左 / 右轮数组索引为 `1 / 0`，对应四通道报文第 **2 / 1** 项；更换接线时同步修改 `APP/motor.h`。

## 编译、手动烧录与首次运行

1. 安装上表中的工具和依赖，在 CCS 中导入本目录下含 `.project` 的工程，核对本机 SDK 和 SysConfig 路径。
2. 选择 `Debug`，执行 **Build Project**，确认编译、链接及 HEX 转换成功。烧录文件为 `Debug/empty_LP_MSPM0G3507_nortos_ticlang.hex`，同名 `.out` 用于调试；构建失败时不要使用残留的旧 HEX。
3. 通过 **UniFlash 手动烧录** HEX 文件。
4. 打开 PC 串口，设置为 `115200 / 8N1`、无流控。程序启动时输出 `...start...`，并向驱动板发送停车指令和 `$upload:0,0,1#`。
5. 确认驱动板持续返回有效 `$MSPD:...#` 速度帧，反馈间隔应显著小于 300 ms；没有有效反馈时，按 K1 会触发保护停车。
6. 首次调试先架空车轮，在待机状态按 K3 关闭巡线，再按 K1 验证速度闭环；确认巡线电平、排列和转向后，再开启巡线测试。

### 按键操作

| 按键 | 待机 / 停止时 | 运行时 |
| --- | --- | --- |
| K1 | 启动 | 停车 |
| K2 | 无操作 | 按 150 → 300 → 600 → 150 mm/s 循环换挡 |
| K3 | 切换巡线开关 | 切换巡线；关闭后按当前档位直行 |

上电默认等待启动，巡线开启。停车后保留当前档位和巡线开关，复位恢复默认值。

全白停车等待期间，K1 或 `03` 取消自动恢复，K2 只更换恢复时使用的档位，K3 关闭巡线后按当前档位直行。手动停止、反馈或控制更新超时、全黑及异常检测停车后，须按 K1 或发送 `02` 重新启动；具体判定见“巡线与停车”。

## 串口协议

### PC 调参与启停（UART0 / UART2）

两路 PC 串口支持相同命令，任选一路使用。在串口工具中选择对应端口，设置 `115200 / 8N1`、无流控，使用 ASCII 文本模式发送。启停直接发送两个字符 `02` 或 `03`，不带引号、`$`、`#`，无需换行。调参命令仍以 `$` 开始、`#` 结束，区分大小写，正文最多 31 个字符；数值和 `#` 之间不要添加额外字符。末尾追加的 `\r\n` 会被忽略。

| 命令 | 示例 | 合法范围 | 应答 |
| --- | --- | --- | --- |
| 设置速度 PI | `$PI:1.5,8.0#` | `Kp`、`Ki` 均为 0～100 | `PI:OK` |
| 设置巡线比例系数 | `$LINEKP:0.1#` | 0～1 | `LINEKP:OK` |
| 启动 | `02` | 无参数 | `START:OK` |
| 停止 | `03` | 无参数 | `STOP:OK` |

应答只返回发送命令的串口，以 `\r\n` 结束。未知、格式错误、超长或越界命令不应答；合法命令未收到 OK 时，检查串口连接并重新发送完整命令，避免一次性下发大量命令。

先完整发送调参命令，再发送启停命令。两路修改同一组参数，以最后执行成功的命令为准。参数只在本次上电期间有效，复位后恢复默认值；修改 PI 会清除积分。换挡仍使用 K2，K1 的启停切换功能保留。

`02` 按当前档位和巡线模式启动；已运行或正在全白停车等待时重复发送不改变状态。`03` 立即停车并取消自动恢复，重复发送保持停车。同一轮同时收到启停请求时，停止优先；之后需单独重新发送 `02` 才能启动。

`START:OK`、`STOP:OK` 仅表示命令应答，不代表小车已运动，也不额外发送 ERR。没有有效速度反馈、反馈超时或巡线触发停车时，保护仍然有效；反馈恢复后不会因之前的 `02` 自动起步。

### PC 速度遥测（UART0 / UART2）

当前主循环中的 `telemetry_task(now)` 已被注释，本次保留该状态。两路仍输出启动提示；如果以后启用速度遥测调用，将每 60 ms 发送相同的一行四通道实际速度，单位 mm/s，每行以 `\r\n` 结束：

```text
150.0,150.0,0.0,0.0
```

速度遥测启用后，没有有效速度反馈或反馈超过 300 ms 未更新时输出 `eeeeeeeeeeeee`，待机、运行和停止时均可发送。调参响应与四路速度数据共用串口，上位机需分别识别。

### 电机驱动板协议（UART1）

| 方向 | 格式 / 命令 | 用途 |
| --- | --- | --- |
| MCU → 驱动板 | `$pwm:p0,p1,p2,p3#` | 四通道 PWM，每项限幅到 −3600～3600 |
| MCU → 驱动板 | `$pwm:0,0,0,0#` | 停车 |
| MCU → 驱动板 | `$upload:0,0,1#` | 启动时请求速度上报，字段语义以驱动板协议为准 |
| 驱动板 → MCU | `$MSPD:v0,v1,v2,v3#` | 四通道实际速度，单位 mm/s |

例如 `$MSPD:150,150,0,0#` 表示左右轮速度均为 150 mm/s。反馈须包含恰好四个数值，各项在 −100000～100000 范围内；从 `$` 到 `#` 之前最多 63 个字符，无效帧不更新反馈。

程序不会自动配置驱动板的电机类型、编码器和轮径等参数，使用前需按实际硬件及驱动板说明设置。

## 巡线与停车

四路传感器按 S0～S3 排列，已确认传感器输出为**白色高电平（1）、黑色低电平（0）**，权重为 `+3、+1、−1、−3`。`Line_Read()` 将 GPIO 电平转换为黑线检测标志：`sensor[i] = 1` 表示黑线，`sensor[i] = 0` 表示白色。下文公式及黑线组合使用此检测标志。

赛道按单根黑线处理，只有连续相邻的 1～3 路黑线属于正常检测；全黑及非相邻组合 `0101、1001、1010、1011、1101` 立即停车，须 K1 或 `02` 重启，当前不识别交叉口。这些组合中的 1 表示检测到黑线，不表示 GPIO 高电平。

按实际 GPIO 电平查看 S0～S3 时，停车情况如下：

| 检测情况 | GPIO 电平（1 高 / 白，0 低 / 黑） | 内部黑线检测标志 | 行为 |
| --- | --- | --- | --- |
| 全黑 | `0000` | `1111` | 立即零 PWM，进入 `MOTOR_STOPPED` |
| 黑线不连续相邻 | `1010、0110、0101、0100、0010` | `0101、1001、1010、1011、1101`（逐项对应） | 立即零 PWM，进入 `MOTOR_STOPPED` |
| 全白 | `1111` | `0000` | 无可靠历史时立即停车等待；有历史时保持偏差，到 200 ms 仍未确认找回则停车等待，主状态保留 `MOTOR_RUNNING` |

巡线每 20 ms 更新一次，正常检测按权重平均得到偏差，并使用下式设置左右目标速度：

```text
line_offset = (3*s0 + s1 - s2 - 3*s3) / (s0 + s1 + s2 + s3)
turn = base_speed * line_kp * line_offset
left_target  = base_speed - turn
right_target = base_speed + turn
```

基础速度保持当前档位。巡线系数默认 0.1，可通过 `$LINEKP:...#` 设置为 0～1，下一次巡线更新生效，设为 0 则取消转向修正。不额外限制或平滑转向，较大系数允许内侧轮目标反转，调试时从默认的小系数开始；PWM 和 PI 积分仍受限幅保护。

巡线及丢线处理如下，丢线时间从最近一次可靠检测开始计算：

| 状态 | 条件与行为 |
| --- | --- |
| 正常巡线 | 按当前检测偏差转向 |
| 间隙保持 | 失检不足 200 ms；全白保持最后可靠偏差，偏差为 0 则直行 |
| 停车等待 | 达到 200 ms 仍未确认找回，或没有可靠历史时遇到全白；停车等待连续 3 次正常检测后恢复 |

间隙保持中连续 2 次正常检测才确认找回；第一次正常检测立即参与转向，但不延长 200 ms 期限，再次全白仍按最后可靠偏差行驶。停车等待期间，前两次正常检测保持停车，第三次按当前档位恢复。达到 200 ms 时停车优先，即使当次检测正常也按停车后的首次确认计数。

等待期间按键、调参和反馈保护仍有效。反馈未收到、超过 300 ms 未更新，或控制更新间隔超过 300 ms 时保护停车，恢复反馈后仍须 K1 或 `02` 重启。启停及巡线模式切换会清除检测历史，保留串口设置的巡线系数。

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 按 K1 后马上停止 | 是否已有新鲜速度反馈；默认巡线是否触发全白 / 全黑；检查传感器电平、接线及 J18/J17 跳线 |
| PC 输出 `eeeeeeeeeeeee` | 检查驱动板供电、UART1 TX/RX 交叉连接、共地、波特率和 `$MSPD:...#` 格式 |
| PC 串口无输出或乱码 | UART0 检查 User UART 端口及 J21/J22；UART2 检查 PA21/PA22 交叉接线、共地、J16 及外接模块端口；均使用 115200 / 8N1 |
| 只能一侧转动或速度反馈通道不符 | 检查第 2 / 1 通道接线、左右轮映射和电机转向 |
| 巡线修正方向相反 | 检查 S0～S3 排列、黑线输出电平及左右轮映射 |
| 按 LaunchPad 自带按键无反应 | 本工程按键接在 PA2 / PB19 / PB20，需按接线表连接 |
| 调参复位后丢失 | 当前没有 Flash 参数持久化，请修改源码默认值或启动后重新下发命令 |
| 编译提示缺少 SDK 或 SysConfig | 在 CCS 中安装并关联工程引用的产品版本，检查本机依赖路径 |
